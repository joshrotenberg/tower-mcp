# Git workflow

1. Branch from `main` using the naming rules in `references/branching.md`.
2. Write commit subjects with a conventional-commit prefix (`feat:`, `fix:`, `docs:`).
3. Open a draft pull request as soon as the branch exists, and mark it ready when CI is green.
